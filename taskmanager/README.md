# Task Manager API

API REST desarrollada con **Spring Boot** para la gestión de tareas.  
-----------------------

## Tecnologías utilizadas

- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Docker

---------------------

## Funcionalidades

- Crear tareas
- Listar todas las tareas
- Obtener tarea por ID
- Marcar tarea como completada
- Eliminar tareas
- Manejo de errores HTTP (404, etc.)
